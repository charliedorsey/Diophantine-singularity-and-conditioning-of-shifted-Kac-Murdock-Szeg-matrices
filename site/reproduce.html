Reproducibility

What is in the archive?

This release includes one mathematical manuscript, its PDF, a pinned Lean 4/Mathlib project and a source-readable HTML companion. No private development logs, historical audit records or internal coordination files are included.

Step 1

Build the formalization

Install Lean and Lake through Elan. In a terminal, enter the included project directory:

cd lean_project
lake exe cache get
lake build KMS ShiftedKMS

The Mathlib dependency is specified in lakefile.toml and lake-manifest.json; the Lean version is specified in lean-toolchain. A clean build requires the platform-appropriate cache and may need network access to fetch dependencies. This is a fresh test only when run locally.

Step 2

Inspect a theorem and its axioms

After the project builds, make a small temporary file in lean_project/ containing these commands:

import KMS.PaperStatements

#print ShiftedKMS.PaperStatement.thm_det
#print axioms ShiftedKMS.PaperStatement.thm_det
#print axioms ShiftedKMS.PaperStatement.thm_main_conditioning

Run the file with lake env lean Check.lean (where Check.lean is the filename you chose). You can repeat the process for any declaration in the atlas.

Step 3

Rebuild the paper PDF

From the archive root, with AMS-LaTeX, TikZ, geometry and hyperref installed:

cd manuscript
latexmk -pdf -interaction=nonstopmode -halt-on-error shifted_kms.tex

The self-contained TeX source generates the academic manuscript. Its visible text, references and mathematical content are the publication source; the companion pages are explanatory navigation, not another edition of the paper.

What the checks mean

Compiler verification is specific

A Lean build checks elaborated formal declarations and proof terms against Lean’s kernel. It does not establish novelty, completeness of literature coverage, or correctness of an informal paraphrase. Likewise, a successful PDF compilation checks typesetting, not the mathematics. An independent pinned Lean source build completed 8,952 jobs successfully on 19 October 2026, and 51 audited declarations use only standard Lean axioms. All mathematical Lean source and build configuration in this companion are byte-for-byte identical to that compiled input. See the verification receipt for scope and reproducibility; auditing a different source version requires another build.

Links to source files and the paper inside this archive work without an internet connection. Downloading Mathlib for a fresh Lean build may require one.
